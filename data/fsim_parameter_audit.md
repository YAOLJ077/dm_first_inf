## 1. 参数来源标注

`fsim_parameters.csv` 共15项：3项开放候选、8项文献关系或借用关系、1项定义固定、1项研究门控、2项计算约定。系数组按一项登记，不能把表格行数理解为标量系数数量。

| 缩写 | 表内证据性质 | 来源标注核查结论 |
|---|---|---|
| VPD_w | 开放候选 | 已标为暂定分析范围；不能称为文献直接确定的默认值。 |
| I_req | 开放候选 | 已说明范围借鉴Hui Wang并经过整理；不是原文范围的逐字复现，也不是置信区间。 |
| u_tr | 开放候选 | 已注明历史值与范围待定；不能称为已验证的文献常数。 |
| RH_sp | 文献固定 | 详细来源表指向Brischetto；简单表缺少年份及可定位出处。 |
| MP_sp | 文献固定 | 详细来源表指向Brischetto；简单表缺少年份及可定位出处。 |
| T_sp | 文献固定 | 表格明确写出代码的边界约定；该约定与原文措辞是否严格等价不在本次数值验收范围内。 |
| theta_sp | 文献固定 | 已列Lalancette–Brischetto来源链；尚未建立原始试验、后续采用与项目改写之间的逐项出处记录。 |
| theta_att | 文献固定 | 详细表及代码注明Brischetto并追溯到Blaeser和Weltzien；原始试验适用范围仍未完整登记。 |
| theta_det | 文献固定 | 同上；文献采用关系与本地适用性应分别记录。 |
| theta_rel | 借用关系 | 已明确跨路径借用属于模型假设；不能将借用表述为在本研究路径中已验证。 |
| theta_inc | 文献固定 | 已注明Rossi；详细来源表中的预设稳健性扰动幅度未附经验依据，不能解释为试验不确定区间。 |
| S_inc | 定义固定 | 分类明确；详细来源表仍有“Keep near one”措辞，与严格固定的表述不一致。 |
| BBCH_min | 研究门控 | 简单表分类恰当；详细表明确FSIM-S尚未同步，简单表未交代此作用域限制。 |
| t_night | 计算约定 | 已明确固定钟表时段是近似，不是实测的当地生物学时刻。 |
| t_init | 计算约定 | 不能等同于生物学季节重置；表中固定日期也不等于核心入口已强制该日期。 |

文献身份及研究主题可追溯至[Rossi等（2008）的作者机构记录](https://publicatt.unicatt.it/handle/10807/37731?mode=complete)、[Brischetto等（2020）出版全文](https://www.frontiersin.org/journals/plant-science/articles/10.3389/fpls.2020.01187/full)及[Brischetto等（2021）出版全文](https://www.frontiersin.org/journals/plant-science/articles/10.3389/fpls.2021.636607/full)。本地书目为`references/reference.bib`。以上来源核查不构成“所有数值与原文完全一致”的结论。

## 2. 配置与入口一致性

| 检查项 | 静态证据 | 结论 |
|---|---|---|
| 固定标签是否意味着禁止覆盖 | `model/config.py`保留可修改配置；两个核心构造器调用`validate_incubation_completion`，但未对全部文献固定项作统一校验。 | 不能声称全部固定项已经锁定；未纳入当前搜索空间与程序禁止覆盖是两回事。 |
| 定义固定项 | `model/process_rules.py`提供共享常量与非默认配置拒绝检查，两个模型均引用。 | 该项已同步并有显式校验。 |
| 系数组的维护位置 | `model/first_infection.py`与`model/first_infection_spore_infthr.py`分别维护同名系数字典。 | 静态查看当前字典一致，但属于重复维护，不是共享的单一来源。 |
| 当前分析入口 | `src/morris_fsim_current.py`的`PARAM_RANGES`仅列两项；版本选择开关与搜索空间分开。 | 与两项共同候选一致；不能将此脚本称为已覆盖全部M1候选的分析。 |
| 历史分析入口 | `src/morris_first_infection.py`、`src/morris_first_infection_spore.py`、`src/morris_first_infection_spore_infthr.py`及`src/bayes_calibrate_first_kfold_spore_infthr.py`仍含旧参数空间。 | 全仓库尚未同步。部分旧项会被新校验拒绝，另有旧项不再被当前核心读取。 |
| 异常记录 | 上述旧脚本及当前Morris入口均有宽泛的`except Exception`处理。 | 配置错误可能被记录为失败或缺失预测；现有记录不足以稳定区分程序错误与模型无预测。 |
| FSIM与FSIM-S作用域 | 默认配置标注了仅供旧FSIM-S使用的字段；两套季节控制器的门控实现不同。 | 局部共享定义不等于两套过程已完全同步；工作流已明确延期处理。 |
| 初始化约定 | 两套季节控制器接收输入天气时间轴，`season_start`初始化为缺失值；输入适配器记录实际天气起点。 | 在所查核心入口未见强制参数表日期的统一校验；不能仅凭表格判定实际输入均符合约定。 |

## 审计结论

来源类别已基本区分，但出处粒度、固定状态的程序保障及历史入口隔离尚不完整。当前状态不支持“全部固定参数已核实为原文默认值且所有分析入口均已同步”的声明。

本次交付的是问题清单，不是修复验收。原有五列表保持不变，避免将尚未完成的数值核验写成已完成；未维护`assessment.md`。
