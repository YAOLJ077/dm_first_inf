# FSIM-S observed-dose extension

`FSIM-S` is the observation-derived extension of the recurrent airborne-
sporangia route. When enabled, a site-year pressure field derived from CK
counts is converted to an external background dose and injected before
dispersal. The weather-cohort gate is applied at production.

The pressure field treats each numeric collection result as an accumulated
count over its exposure interval. It distributes `Spore / exposure_days` over
`(interval_start, interval_end]`, applies measured-period z-score
normalization, smooths with a three-day centered mean, and centers on
`reference_level`. The dose provider uses the single extension parameter
`beta_sp`:

```text
background dose = beta_sp * max(centered pressure, 0)
```

Numeric zero-spore collection intervals suppress weather-generated cohorts.
Missing observations and dates outside the monitoring period do not suppress
weather production. If weather and observed background would otherwise form a
mixed cohort, the observed component is retained.

The deployment configuration uses `zscore`, `rolling_days=3`,
`reference_level=0.5`, `observed_zero_weather_gate=true`, and
`beta_sp=0.005`. The extension remains disabled unless explicitly enabled for
a run.

`beta_sp = 0` (or a zero pressure field) reproduces FSIM exactly. Blank CK
cells are missing results and are never converted to zero. The first measured
interval is `(t_first - 3 days, t_first]`; later intervals use consecutive
nonblank collection dates.

Example:

```bash
PYTHONPATH=. python run/run_spore_plus.py \
  --weather data/weather_data/site_year/23_83_108_1_2022.json \
  --spore-file data/spore_data/guangxi_site_years_spore_data.xlsx \
  --enable --pressure-config result/deployment_parameters/fsim_s_deployment_config.json \
  --output result/FSIM-S/23_83_108_1_2022.json
```

The CK workbook now contains six monitored Guangxi site-years, including
Guilin 2022. Blank cells remain missing results; numeric zeroes are valid
zero-count intervals. The first interval is `(t_first - 3 days, t_first]`.

The single deployment parameter set is generated by
`src/select_deployment_parameters.py` and written to
`result/deployment_parameters/`.
