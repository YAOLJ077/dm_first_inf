# Guangxi S-route model package

This package contains the two process routes retained for the current study:

- `FSIM`: weather-triggered asexual-sporangia cohorts through wind
  transfer, rain deposition, survival, infection and symptom appearance.
- `FSIM-S`: FSIM-S, which injects an observation-derived background dose
  before dispersal and then reuses the same process chain.

`phenology` supplies the optional host-susceptibility modulation used during
the hourly infection check. Oospore and regional north/south disease routes
are outside this repository's six Guangxi site-year analysis.
