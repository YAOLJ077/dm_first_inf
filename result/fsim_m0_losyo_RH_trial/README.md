# M0 新增 RH_sp 的 LOSYO 试验

RH候选：[75, 80, 85, 90]%。这些是离散探索值，不是已验证的连续生物学范围。
每个RH切片分别按相同范围和三轮二维加密校准VPD_w、I_req，再依据五个训练站点的MAE选取RH。MP_sp和其他参数不变。
RH=80复用已完成基线。其他RH通过每个独立进程池的运行配置传入模型，缓存不跨RH切片复用；每个切片的 effective_runtime_config.json 记录真实配置。
三参数选参仅接收训练损失面。RH并列时优先离80最近者，再按RH、VPD_w、I_req升序；冻结选择后才读取相应留出结果。

## 本轮复核结论

五折训练MAE降低，一折不变；六个相互重叠的训练折MAE的描述性均值由12.8736降至11.8750天。留出MAE却由33.7431升至45.4306天，RMSE由39.6109升至49.2673天。主要恶化发生在DA_MPT_2023和NN_JF_2024，其余四个留出误差保持一致。因此本次离散RH候选和搜索设置不支持替换原RH=80的两参数基线，不能据此断言RH在所有设置下无效。

24个RH切片折中，RH=90、留出NN_JF_2023的最后一轮训练MAE仍下降0.175天；本轮不是所有切片的严格收敛证明。其余切片的最后一轮改善均不超过0.05天。五折RH选到离散候选端点，提示候选选择不稳定，但不自动扩界。

60项测试通过。运行配置仅改变RH、24个切片选参、6个联合选参、留出记录映射及全部汇总指标均复核通过；验证记录见verification.json。
